# starbot

starbot is a simple slack bot made for the Stardance Slack Bot mission.

The bot has some simple commands that can be used directly in Slack.

## Commands

`/starbot-ping`
Checks if the bot is online.

`/starbot-joke`
Sends a random programming joke.

`/starbot-help`
Shows the available commands.

## Apps used

* VS Code for coding
* YouTube for tutorials
* Lapse / Hackatime to log my hours
* Slack to create and test the bot
* Railway to keep the bot online
* GitHub to store the code

## Programming languages used

* Python
* HTML
* CSS

## How it works

The bot uses Slack Bolt with Socket Mode.

The bot connects to Slack using a bot token and an app token.
Railway runs the Python program so the bot can stay online even when my PC is off.
